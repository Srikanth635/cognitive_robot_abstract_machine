Important findings:
 - MixingAction needs a specific bounded refinement; generic tool use is
   not full mixing semantics. No speculative ontology extension was added.
 - PickAndPlaceAction does not require base navigation; add a no-navigation
   recipe instead of forcing it into the current pick/carry/place family.
 - Full TransportAction and move-and-act/face-look wrappers need reviewed
   compositions and field mappings. Sustained carrying is narrower.
 - Existing elevator/inter-level profiles already have cabin/door guards,
   entry/ride/exit and final exit criteria. Reuse them; map source reference
   reattachment and add bounded monitor/timeout/recovery contracts as needed.
 - Pouring/wiping/cutting path completion is not evidence of the stronger
   ontology physical outcomes. Keep code completion, task outcome and evidence
   acceptance separate. Broader repo measurement components may add evidence.
 - Generic action schemas do not implement every specialized scientific CQ:
   estimator memory/efference copies, learning-stage/adaptation distinctions,
   grip/load coupling, proactive gaze and attenuation need selected extensions.
 - The standalone ontology package is not established as integrated with the
   repo's existing LLM/EQL/storage/measurement components or pushed to GitHub.
